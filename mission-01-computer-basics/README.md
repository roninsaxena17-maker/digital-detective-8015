# Mission 1 — Know Your Computer

## 1. Task / objective
Understand how computers receive input, process data, produce output and store information. Identify hardware, software and everyday computer systems.

## 2. Work completed

### Task 1.1 — IPOS

Example: Searching Google using a computer.

| Stage | What happens | Hardware/component |
|---|---|---|
| Input | I type a search query using the keyboard. | Keyboard |
| Processing | The processor handles browser operations and processes received data. | CPU and RAM |
| Output | Google displays search results on the screen. | Display |
| Storage | Browser data and downloaded information can be saved. | SSD |

## 4. My understanding
IPOS describes the basic working cycle of a computer. Input provides data, processing handles it, output presents the result and storage saves information. Hardware refers to physical components, while software consists of programs and instructions.
