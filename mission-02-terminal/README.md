## 3. Commands / tools used
- pwd: Displays the current directory.
- ls: Lists directory contents.
- cd: Changes directory.
- mkdir: Creates directories.
- touch: Creates empty files.
- cp: Copies files.
- mv: Moves or renames files.
- cat: Displays file contents.
- echo: Prints text.
- >: Replaces file contents.
- >>: Appends text.
- ls -lah: Displays detailed information including hidden files.
- head: Displays the first lines of output.
- |: Passes output between commands.
- Homebrew: Package manager for macOS.

## 4. My understanding
The Terminal allows me to interact with my computer using commands. Copying creates another version of a file, whereas moving changes its location or name. The > operator replaces file contents, while >> adds text without removing existing content.

Flags modify how commands behave. A pipe connects commands by passing the output of one command to another. Package managers help install, update and manage software.
