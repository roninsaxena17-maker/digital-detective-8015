# Task 7.1 — Network Concepts

| Concept | Explanation | Example |
|---|---|---|
| LAN (Local Area Network) | A network connecting devices in a small area. | Home Wi-Fi or computer lab |
| MAN (Metropolitan Area Network) | A network covering a city or a large campus area. | A network connecting locations across a city |
| WAN (Wide Area Network) | A network covering a large geographical area, connecting smaller networks. | The Internet |
| DNS (Domain Name System) | Converts a domain name into an IP address that computers can use to find a server. | Resolving google.com |
| Router | A device that connects networks and forwards data between them. | A home Wi-Fi router |
| Protocol | A set of rules that devices follow to communicate. | HTTP or HTTPS |
| Packet Switching | Data is split into packets that travel through a network and are reassembled at the destination. | Data travelling across the Internet |
| Client-Server | A client requests something and a server provides it. | A browser requesting a webpage from a web server |
