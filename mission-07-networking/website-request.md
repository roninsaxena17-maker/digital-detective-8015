# Task 7.3 — What Happens When I Open a Website?

1. I enter a website URL into my browser.
2. The browser checks whether it already has the IP address cached. If not, it requests the IP address through DNS.
3. DNS resolves the domain name into an IP address.
4. My computer establishes a connection with the web server using the network protocols.
5. The browser sends an HTTP or HTTPS request to the server.
6. The server processes the request and sends back webpage data.
7. The browser interprets the HTML, CSS, and JavaScript and displays the webpage.
