# Mission 7 — Networking

## Objective
Understand basic networking concepts and observe how my computer communicates over the internet.

## Concepts Learned
- LAN (Local Area Network)
- MAN (Metropolitan Area Network)
- WAN (Wide Area Network)
- DNS (Domain Name System)
- Router
- Protocols
- Packet Switching
- Client-Server Model

## Practical Activities
- Used `ping -c 4 example.com` to test connectivity.
- Observed packet transmission, packet loss and response time.
- Used `nslookup example.com` to perform a DNS lookup.
- Observed how a domain name resolves into IP addresses.

## Files in This Mission
- `network-concepts.md` — explanations of networking concepts.
- `network-tests.md` — ping and DNS test results.
- `website-request.md` — steps involved in opening a website.

## What I Learned
I learned how devices communicate over networks, how DNS resolves domain names into IP addresses, and how to use Terminal commands to test connectivity and perform DNS lookups.

## Difficulties Faced
Understanding networking terminology and how DNS translates domain names into IP addresses was initially challenging. Performing the tests helped me understand the concepts better.
