# The Digital Detective

## About

The Digital Detective is a Diwali independent learning assignment focused on understanding how computers work, exploring the command line, learning about operating systems, programming, number systems, Git, GitHub, and computer networking.

This repository contains the work completed across all nine missions of the assignment.

## Topics Explored

- Computer fundamentals and the IPOS cycle
- Hardware and software
- Terminal commands, directories, files, flags and pipes
- Operating systems, processes, paths, storage and permissions
- Python programs, compilers and interpreters
- Binary, decimal, octal and hexadecimal number systems
- Text encoding and data representation
- Git, GitHub, branches and Pull Requests
- LAN, MAN, WAN, DNS, routers, protocols and client-server architecture

## Running the Number Converter

From the repository root, run:

    cd mission-05-numbers-data
    python3 number_converter.py

Follow the instructions displayed by the program to perform number-system conversions.

## Learning Summary

Throughout this assignment, I explored how computers work, practiced Terminal commands and file management, learned how operating systems handle processes and permissions, wrote and executed Python programs, and understood how numbers and text are represented digitally.

I also practiced Git and GitHub by creating commits, working with branches, pushing changes and creating a Pull Request. Networking activities helped me understand how devices communicate and how a browser accesses websites.
