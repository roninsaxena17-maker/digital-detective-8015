## Task 4.2 — Compiler vs Interpreter

| Compiler | Interpreter |
|---|---|
| Translates source code before execution. | Executes instructions at runtime. |
| Often produces compiled code or an executable. | Typically runs code without producing a standalone executable. |
| Compiled programs can often execute faster. | Convenient for testing and development. |
| Example: GCC compiler for C. | Example: Python interpreter. |

### Explanation

A compiler translates source code before it is executed, while an interpreter executes instructions at runtime. Compiled programs can often execute faster because translation has already happened. Interpreters make testing and development convenient. Python uses an interpreter to run programs, although CPython also compiles code into bytecode internally.
